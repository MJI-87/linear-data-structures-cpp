This structure is written as a simple game 
to simulate rotation from the last node to the starting node.
The idea is simply that the game consists of two players who enter 
a specific number, multiplied by 2, and the result of the multiplication 
is divided by the number 2, and the final result is checked whether it is even or odd? 
If it is even, the player who reached the even score increases one point, and so on, 
and each player has five rounds
